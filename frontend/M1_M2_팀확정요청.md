# M-1 · M-2 팀 확정 요청

화면에 임시안으로 구현해 둔 규칙 중, **팀 확정이 필요한 것**을 모아둔 문서입니다.
확정 전까지 각 화면에 "미결 — 팀 확정 전 임시안" 표시를 남겨 둡니다.

---

## M-1 — "검증 실행" 버튼을 언제 막을 것인가

**어디에 있나**: `src/pages/S3Draft/VerifyBar.tsx`, 규칙은 `constants/domain.ts`의
`canTransitionToVerified`

**지금 임시안**

검증 실행을 막는 조건 두 가지:

1. 필수 확인(REQUIRED) 필드가 1건 이상 남아 있음
2. 미해결 Critical 위반이 1건 이상 있음 (`severity: Critical` + `result: VIOLATION`)

둘 중 하나라도 걸리면 버튼을 비활성으로 두고, "사유 기록 후 강제 실행"을 따로 제공합니다.

**확정이 필요한 것**

- 위 두 조건이 맞는가? 다른 조건이 더 필요한가?
- 강제 실행을 허용할 것인가. 허용한다면 사유를 어디에 남기고 누가 보는가
  (`StatusOverride` 타입은 이미 있지만 저장 경로가 없음)
- 강제 실행 시 판정 보류(DEFERRED) 건은 어떻게 처리하는가

## M-2 — 사람이 값을 건드렸을 때 신뢰도 등급을 어떻게 볼 것인가

**어디에 있나**: `src/shared/shipmentStats.ts`의 `effectiveGradeOf`, `resolveConflicts`

### 핵심 질문

**"사용자가 직접 입력한 값"과 "제시된 후보 중 선택"은 다른 행동인데,
지금 `isEditedField`가 둘을 같게 묶고 있습니다.**

두 행동의 성격이 다릅니다:

| | 직접 입력 | 후보 선택 |
|---|---|---|
| 무엇을 하나 | 사람이 새 값을 써넣음 | 원문에서 이미 읽어낸 값 중 하나를 고름 |
| 근거 | 사람의 판단 (원문 근거 없음) | 그 후보의 bbox·출처·신뢰도가 그대로 있음 |
| 인식 품질 | 해당 없음 | 고른다고 원문 인식 품질이 좋아지지 않음 |

### 지금 임시안

**직접 입력** → 무조건 `CONFIRMED`(확정)로 올립니다.

```ts
export function effectiveGradeOf(field, editedValues) {
  return isEditedField(field, editedValues) ? 'CONFIRMED' : toConfidenceGrade(field);
}
```

**후보 선택** → `resolveConflicts`가 그 필드를 고른 후보로 갈아끼웁니다.
충돌만 해소(`conflict_flag: false`)하고, 등급은 **그 후보가 원래 갖고 있던 신뢰도**를
그대로 따릅니다.

- BUSAN(신용장, 0.90) 선택 → 확정
- INCHEON(선적요청서, 0.71) 선택 → 확인 권고

### 왜 이렇게 나눴나

2026-08-16 논의에서 나온 근거입니다.

1. **BUSAN을 골랐을 때 아무 반응이 없는 건 명백한 버그였습니다.**
   `isEditedField`가 "원본 값과 다른가"로 판단하는데 원본이 이미 BUSAN이라,
   확정 동작을 했는데도 화면이 안 바뀌었습니다.
2. **"고르면 무조건 확정"은 0.71을 고른 것과 0.90을 고른 것을 같게 취급합니다.**
   낮은 쪽을 고르는 게 더 위험한 선택인데 오히려 확정으로 올라가면
   시스템이 위험을 감추게 됩니다.
3. **사람이 골랐다는 사실이 원문의 인식 품질을 바꾸지는 않습니다.**

### 확정이 필요한 것

- 위 구분(직접 입력 = 확정 / 후보 선택 = 후보의 신뢰도)이 맞는가?
- **직접 입력을 확정으로 올리는 게 맞는가?** 지금은 사람이 아무 값이나 써넣어도
  확정이 됩니다. 원문 근거가 없는 값인데 "확정"이라고 부르는 게 맞는지,
  아니면 별도 등급(예: "사용자 입력")이 필요한지
- 후보 선택 후 그 필드가 여전히 "확인 권고"로 남으면, 검증 실행은 가능하지만
  리포트에 미확인 항목으로 기재됩니다. 이게 의도한 동작인가?
- 후보 선택을 되돌리는(취소) 동작이 필요한가
